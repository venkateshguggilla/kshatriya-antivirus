# Kshatriya brand assets

The Kshatriya emblem shows an archer drawing a recurved bow, after the warrior
archers of Indian epic tradition ("Kshatriya" means warrior).

| File | Use |
| --- | --- |
| `kshatriya-emblem.png` | Master artwork, 1024 × 1024, cream background |
| `kshatriya-icon-512.png` | Rounded-square app icon, 512 × 512 |
| `kshatriya.ico` | Windows icon, 16–256 px (copied to `src/Kshatriya.App/Assets`) |

Provenance: the artwork was supplied by the project owner on 2026-11-10 for use
as the project logo. The PNG and ICO files are generated from it (square crop
on the original cream background, rounded corners for the icon). To change the
logo, replace the master artwork and regenerate every file in this table and
`src/Kshatriya.App/Assets/emblem-256.png`.

At 16 px the full figure loses detail; it stays recognisable from 24 px up.
